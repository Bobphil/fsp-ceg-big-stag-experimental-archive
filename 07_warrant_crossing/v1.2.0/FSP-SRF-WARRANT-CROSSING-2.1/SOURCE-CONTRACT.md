# Source Contract

The canonical source for 2.1 is the executable `FSP-SRF-WARRANT-CROSSING-2` lineage plus the demonstrated failures in `FSP-SRF-WARRANT-CROSSING-STRESS-1`.

2.1 does not alter the basic crossing grammar:

`X0 Presented → X1 Intelligible → X2 Evidentially Receivable → X3 Warrant-Licensed → X4 Action-Compatible → X5 Standing-Qualified → X6 Authorized → X7 Consequentially Retained`

It preserves the central independence:
- X3 is not required for X4 when a receiver has a supported alternative warrant.
- X4 is never sufficient for X6.

The patch changes only the governance conditions under which standing, authorization, coalition recomposition, residue preservation, and REOPEN may count as current and valid.
