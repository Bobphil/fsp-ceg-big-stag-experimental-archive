# LICENSE DECISION — ADOPTED

**Decision date:** 2026-11-23  
**Status:** FROZEN FOR v1.1.0 PUBLICATION

The archive explicitly adopts the following dual-license structure:

- **Executable code:** MIT License
- **Prose, audits, explanatory documentation, diagrams, tables, and other original non-code materials:** Creative Commons Attribution 4.0 International (CC BY 4.0)

## Scope

Original executable source code, scripts, test harnesses, and associated software documentation authored for this project are covered by the MIT License.

Original prose, audit records, explanatory documentation, diagrams, tables, and other non-code research materials authored for this project are covered by CC BY 4.0.

Historical ZIP packages may contain both categories; the applicable license follows the material type unless a file contains a more specific notice.

Third-party materials are not relicensed by this decision and remain subject to their original copyright and license terms.

## Canonical license files

- `LICENSE.md` — archive-wide dual-license notice
- `LICENSE-CODE` — MIT License
- `LICENSE-CONTENT.md` — CC BY 4.0 content notice
